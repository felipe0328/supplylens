# Engineering Specifications

This directory contains canonical, reusable definitions for engineering workflows that need more detail than `AGENTS.md`. These documents are written so contributors can follow them directly and future automation skills can consume the same source instead of maintaining a separate policy.

## Available specifications

- [`pull-request-definition.md`](pull-request-definition.md): required scope, content, validation, and review expectations for SupplyLens pull requests.

Specifications describe repository policy. Update them only when the developer explicitly requests a policy change.
